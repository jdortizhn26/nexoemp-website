de la serie.** Todo documento nuevo o actualizado se guarda y versiona aquí —

## Convención

- Los documentos se numeran (`NN-titulo-en-kebab.md`) y se referencian entre sí
  por número.
- Cambios vía rama `claude/*` → merge a `main` (el sitio se despliega desde
  `main`, pero `docs/` no afecta al sitio público).
